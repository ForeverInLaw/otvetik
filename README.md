# Otvetik

<img src="docs/otvetik-mascot.png" alt="Попугай Otvetik с голубым пузырём ответа" width="240">

Предлагает ответ в твоём стиле прямо в личном диалоге AyuGram или exteraGram.
Берёт до 10 твоих и 10 сообщений собеседника, обращается к твоей модели и вставляет результат в поле ввода.
Отправляешь сообщение ты.

Иконка плагина: [стикерпак Otvetik](https://t.me/addstickers/OtvetikPlugin).

## Установка

1. Скачай `otvetik.plugin` на телефон.
2. В настройках плагинов разреши установку из неизвестных источников.
3. Открой файл через AyuGram или exteraGram и включи плагин.

Нужен Python Plugins SDK версии 1.4.5.0 или новее.
Установка, пункт меню и настройки проверены на AyuGram с SDK 1.4.5.7.

## Настройка

В настройках Otvetik заполни три поля. Готовых значений и встроенного ключа нет.

| Поле | Что указать |
| --- | --- |
| Base URL | Адрес OpenAI-совместимого API, например `https://example.com/v1` |
| Модель | Точный идентификатор модели у твоего провайдера |
| API-ключ | Твой ключ для этого сервера |

Плагин использует `POST /chat/completions`. Можно указать и полный URL этого метода.
Выбирай модель с поддержкой Chat Completions и системных инструкций.
Глазик в диалоге API-ключа показывает и скрывает введённое значение.

## Как получить ответ

1. Открой личный диалог.
2. Открой меню входящего текстового сообщения и выбери **Плагины > Предложить ответ**.
3. Проверь готовый черновик, при необходимости поправь и отправь.

Контекст заканчивается выбранным сообщением. Если выбрать старое, более новые сообщения в запрос не попадут.
Сообщения каждого участника выбираются отдельно, затем передаются модели в хронологическом порядке.
Пересылки и сообщения без текста пропускаются. Подписи к медиа учитываются как текст.

Если поле ввода уже заполнено, Otvetik попросит подтвердить замену черновика.
После перехода в другой диалог или аккаунт результат туда не вставится.
Редактируемые сообщения плагин не меняет.

## Данные и ограничения

- Запрос выполняется только по нажатию **Предложить ответ**. Автоматической отправки сообщений нет.
- Текст выбранного контекста отправляется на сервер из Base URL с твоим API-ключом. Плагин не добавляет к запросу профиль, ID аккаунта, телефон или вложения. Содержимое сообщений передаётся целиком.
- Ключ хранится в настройках SDK на устройстве. Плагин не пишет ключ, контекст или ответ модели в журнал и не хранит отдельную копию истории.
- Плагин просматривает не более 1000 сообщений, чтобы найти по 10 текстовых с каждой стороны. Если сообщений меньше, использует доступные.
- Поддерживаются обычные личные диалоги. Группы, каналы и секретные чаты не поддерживаются. Ответ модели требует проверки, она может ошибиться в фактах и стиле.

HTTP поддерживается для локальных серверов. Для удалённого API используй HTTPS.
Ожидание ответа сервера ограничено 60 секундами. Одновременно выполняется один запрос.

## Разработка

На компьютере нужен Python 3.11 или новее. На телефоне нет дополнительных Python-зависимостей.

```powershell
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
ruff check .
ruff format --check .
```

`otvetik.plugin` является копией `otvetik.py` с другим расширением, без сборки и упаковки зависимостей:

```powershell
New-Item -ItemType Directory -Force dist
Copy-Item otvetik.py dist/otvetik.plugin
```

Тесты проверяют отбор контекста, реальный HTTP-запрос к локальному серверу, обработку ошибок и защиту черновика.
Android API в тестах заменён заглушками. Для проверки своего провайдера введи настройки на телефоне.

Документация: [Plugins SDK](https://plugins.exteragram.app/docs), [Telegram messages.getHistory](https://core.telegram.org/method/messages.getHistory).
